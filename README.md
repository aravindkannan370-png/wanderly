# Wanderly 🌍

Wanderly is a modern travel and tourism website designed to help users discover destinations and explore curated travel packages.

## Features

- Responsive travel website
- Hero section with call-to-action
- Popular destinations
- Featured travel packages
- Why Choose Us section
- Final travel CTA
- Responsive mobile navigation
- Contact and footer section

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design

## Destinations

- Bali
- Dubai
- Maldives
- Switzerland
